Entry for make.fun bounty **The Painfully Honest Out-of-Office** ($2 pool): one original out-of-office auto-reply, at most 200 characters, painfully honest about the sender's inbox yet polite enough to keep them employed, judged pairwise by a house judge that weighs honesty first, then politeness, then the turn of phrase.

`main.py` (Python 3, standard library only) writes one sentence to `/output/entry.txt`:

> I'm away until Monday, and honestly I have 1,247 unread emails and no plan to read them in order, so please resend anything urgent and I'll answer it properly when I'm back.

The reply is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
